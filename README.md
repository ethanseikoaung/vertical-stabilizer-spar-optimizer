# Cal Aerospace SAE Biplane Vertical Stabilizer Spar Optimizer

### About
Design of a lightweight vertical stabilizer for the Cal Aerospace SAE biplane. The structure was sized for aerodynamic loads up to 20 N and built around readily available balsa stock. MATLAB calculations compared candidate spar cross-sections to identify the minimum-area option.

## Results

### Optimal Geometry

| Parameter | Value |
|---|---|
| Optimal Height | 0.006350 m |
| Optimal Width | 0.027800 m |
| Optimal Cross-Sectional Area | 0.000177 m² |
| Weight | 0.137031 N |
